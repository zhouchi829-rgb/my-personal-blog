个人博客服务器开机自启动设置说明
====================================

问题描述：
每次电脑开机后，个人博客网站无法访问（http://localhost:3000 打不开）

问题原因：
Node.js服务器没有设置为开机自启动，需要手动启动。

解决方案（三种方法，任选其一）：

方法一：使用启动文件夹（最简单）
--------------------------------
1. 按 Win + R 打开运行对话框
2. 输入 shell:startup 并按回车
3. 将 "start_server.vbs" 文件复制到此文件夹
4. 重启电脑测试

方法二：使用任务计划程序（推荐）
--------------------------------
1. 右键点击 "setup_autostart.ps1" 文件
2. 选择 "以管理员身份运行"
3. 按照脚本提示完成设置
4. 重启电脑测试

方法三：手动设置任务计划程序
----------------------------
1. 按 Win + R，输入 taskschd.msc 打开任务计划程序
2. 点击 "创建基本任务"
3. 名称：个人博客服务器自启动
4. 触发器：计算机启动时
5. 操作：启动程序
6. 程序或脚本：node.exe
7. 参数：server.js
8. 起始于：C:\Users\Lenovo\Desktop\my-personal-blog
9. 完成设置

方法四：创建Windows服务（最稳定）
--------------------------------
1. 下载 NSSM 工具：https://nssm.cc/download
2. 解压到任意目录
3. 以管理员身份打开命令提示符
4. 切换到NSSM目录
5. 执行：nssm install PersonalBlogServer
6. 设置：
   - Path: C:\Program Files\nodejs\node.exe
   - Startup directory: C:\Users\Lenovo\Desktop\my-personal-blog
   - Arguments: server.js
7. 启动服务：net start PersonalBlogServer

已创建的文件：
-------------
1. start_server.bat      - 手动启动脚本（双击运行）
2. start_server.vbs      - 静默启动脚本（用于开机自启动）
3. setup_autostart.ps1   - 自动设置脚本（以管理员运行）
4. 本说明文件

测试方法：
---------
1. 重启电脑
2. 等待1-2分钟让系统完全启动
3. 打开浏览器访问：http://localhost:3000
4. 如果能看到博客首页，说明设置成功

故障排除：
---------
1. 如果仍然无法访问，检查Node.js是否安装：
   - 打开命令提示符，输入：node --version

2. 检查端口是否被占用：
   - 按 Ctrl + Shift + Esc 打开任务管理器
   - 查看是否有多个node.exe进程
   - 如果有，结束所有node.exe进程，然后重新启动

3. 手动启动测试：
   - 双击 start_server.bat
   - 观察是否有错误信息
   - 如果正常，会显示服务器启动信息

4. 检查防火墙设置：
   - 确保允许Node.js通过防火墙
   - 控制面板 -> Windows Defender 防火墙 -> 允许应用通过防火墙

联系支持：
---------
如果以上方法都无法解决问题，请检查：
1. Node.js是否正确安装
2. 项目文件是否完整
3. 数据库文件是否存在
